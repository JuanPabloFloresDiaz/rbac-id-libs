# Referencia rbac-core

## Endpoints usados por helpers HTTP
- `POST /auth/login`
- `POST /auth/logout`
- `GET /user-sessions/verify-session`
- `GET /users/:id/application/:appId/get-user-type-actions`

## Notas
- `debugMode: true` fuerza permisos en `true`.
- `loginRoute` es solo para `rbac-vue`.
